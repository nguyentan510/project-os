# P-00 · Tiếp nhận ý định

**Vai:** Orchestrator · **Đầu ra:** Lời nhắc lại + prompt đích
Sinh từ `docs/PROCESS.md` mục 13. Sửa ở đó trước, rồi sửa file này cho khớp. Thay các chỗ `<…>` trước khi gửi.

```
Tôi nói bằng lời thường, không kèm mã: <lời của tôi>. Tiếp nhận theo PROCESS.md mục 14: (1) xác định ý định; (2) tự tra mã bằng `python pos.py find`, tôi không cần nhớ mã; (3) thiếu thông tin thì hỏi tối đa 3 câu dạng lựa chọn, khuyến nghị đứng đầu; (4) nhắc lại theo mẫu "Tôi hiểu là…" và chờ tôi xác nhận; (5) chuyển sang prompt đích và làm theo luồng chung. Luôn ghi tên gọi trước, mã trong ngoặc.
```
