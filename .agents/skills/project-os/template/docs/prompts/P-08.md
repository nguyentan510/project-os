# P-08 · Merge và dọn

**Vai:** Orchestrator · **Đầu ra:** main mới, STATUS mới
Sinh từ `docs/PROCESS.md` mục 13. Sửa ở đó trước, rồi sửa file này cho khớp. Thay các chỗ `<…>` trước khi gửi.

```
PR <#n> đã qua CI (và đã được approve nếu Lane Strict). Merge squash, `python pos.py done T=<mã>`, chạy `python pos.py status` để thấy task đã xong và task nào sẵn sàng tiếp (không tick tay). Task hoàn tất một feature thì đổi trạng thái feature đó sang `dùng` trong sổ mã.
```
