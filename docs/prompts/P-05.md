# P-05 · Sửa nhanh

**Vai:** Builder (solo) · **Đầu ra:** PR nhỏ
Sinh từ `docs/PROCESS.md` mục 13. Sửa ở đó trước, rồi sửa file này cho khớp. Thay các chỗ `<…>` trước khi gửi.

```
Lane Fast, mã <MAP-02>: <việc cần sửa>. `python pos.py task T=<mã> N=<short-name> TYPE=fix` → sửa → `python pos.py check` → PR. CI qua thì merge squash và `python pos.py done T=<mã>`. `python pos.py scope` báo vượt giới hạn Lane Fast thì dừng: việc này cần thẻ.
```
